# 📋 Validação de Formulário

🚀 Projeto simples de validação de formulário utilizando **HTML, CSS e JavaScript**.

## 📌 Sobre o Projeto
O projeto consiste em um formulário que recebe dois números (A e B) e verifica se **A é menor que B**. Se a condição for atendida, uma mensagem de sucesso é exibida; caso contrário, uma mensagem de erro aparece.

## 🛠️ Tecnologias Utilizadas
- HTML5
- CSS3
- JavaScript

## 🎯 Funcionalidades
✅ Impede o envio do formulário sem validação.

✅ Exibe mensagens dinâmicas informando se A é menor ou maior que B.

✅ Reseta os campos após cada envio.

✅ Feedback visual com estilos CSS.
